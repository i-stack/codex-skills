# checkpoint-persist Agent 调用指南

## 一句话描述

多步骤 / 多子项长任务的中间结论增量落盘——每产出一个子结论立即写入 `<工作区根>/.plan-reviews/checkpoint/<task-slug>/CHECKPOINT.md`，防止上下文超窗 / 压缩导致已产出结论丢失。全局门控，不绑定 plan-grill 盘问或任何特定 skill。

## 何时调用

- **门控触发（CP-001）**：三条全满足才落盘——（1）非平凡任务（构建 / 修改 / 方案 / 迁移 / 审查 / 排障，复用 HR-001 定义）；（2）存在 ≥2 个需分别产出的子结论（多个需求 / 模块 / 决策点）；（3）子结论需跨轮存活（后续引用前面）。
- **跳过**：trivial 任务、单轮可完成、单点子结论、事实查询 / 翻译 / 简单解释 / typo / 小命令 / 纯闲聊。

## 关键行为

1. 阅读 `SKILL.md` + `references/checkpoint_persist.md` 全文。
2. **只落结论**：每条子结论记「结论 + 关键决策 + 未决问题」，自包含；不落对话过程与思考流。
3. **立即落盘**：每产出一个子结论立即追加写 `<工作区根>/.plan-reviews/checkpoint/<task-slug>/CHECKPOINT.md`，禁止攒批。
4. **新轮次恢复**：动手前若存在「进行中」checkpoint，先读取恢复上下文再继续；忘记 slug 时按 mtime 取最近进行中文件。
5. **完成后清理**：结论已写入成品产出（PLAN.md / 代码 / 审查结论）后删除 checkpoint。
6. **失败兜底**：写盘失败不阻断主任务，但须在 GR-008 残留风险中声明「checkpoint 未落盘，超窗后可能丢失」。

## 不调用的情况

- 门控未命中的 trivial 任务、单轮任务、单点子结论。
- 纯事实复述、翻译、闲聊。
- 任务无任何「跨轮存活的中间结论」需要保护。
